## 一句話結論

測指尖（遠端指腹、掌面），不是手掌根，也不是腳掌。只有指尖有完整常模，也只有指尖適用
「2 秒」這個門檻；胸骨與腳掌的正常上限約 4 秒，手掌根沒有常模。

證據以 OpenEvidence 檢索（2026-08-17），主要來源為 Fleming 2015 系統性回顧
（Arch Dis Child）與 meta-analysis（PLoS One）。所有引用在頁面上都可點開原文（DOI）。
